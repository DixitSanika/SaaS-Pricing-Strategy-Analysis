# SaaS Pricing Strategy Analysis
An interactive Power BI project analysing SaaS subscriptions, customer behaviour, revenue, discounts, and pricing-plan performance.

- Project Overview:
This project uses a synthetic SaaS dataset to explore business performance and support data-informed decisions about subscriptions and pricing.

- Dashboards:
1. Executive Overview --- Revenue, active subscriptions, customers, and monthly trends.
2. Customer Behaviour --- Subscription activity, upgrades, downgrades, and plan changes.
3. Revenue & Discount Analysis --- Revenue by plan, discount patterns, and monthly trends.
4. Pricing Recommendations --- Pricing-plan comparisons, revenue contribution, and subscription performance.
   
- Tools & Skills:
 1. Microsoft Power BI
 2. Power Query
 3. DAX
 4. Data Modelling
 5. Data Analysis & Visualisation
  
- Dataset:
The Excel workbook contains five tables:

Table             Records
Customers           1,800
Plans                   4
Subscriptions       1,800
Payments           21,413
Plan_Changes          573

- Business Use:
The dashboards help explore revenue trends, compare pricing plans, understand customer plan changes, and review discount patterns. These insights can support decisions by management, finance, marketing, and customer-success teams.

- Note: This is a portfolio project using synthetic data. Findings are illustrative and do not represent an actual company's performance.
